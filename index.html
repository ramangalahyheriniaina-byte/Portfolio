01 Développement · CI/CD

Application CRM & Pipeline CI/CD

Contexte : Projet de stage chez Eray Digital visant à moderniser le déploiement d'une application de gestion client.

  • Défi : Eliminer les déploiements manuels et isoler les environnements d'exécution.
  • Solution : Conteneurisation de l'application (Symfony/React) sous Docker avec Nginx et automatisation du pipeline via Jenkins.
  • Résultat : Automatisation complète du déploiement à chaque push de code.
  • Symfony
  • React
  • Docker
  • Nginx
  • Jenkins

02 Infrastructure · Supervision

Infrastructure DevOps 3-Tiers Automatisée

Contexte : Déploiement d'une architecture distribuée sur 3 serveurs Linux Ubuntu virtualisés.

  • Défi : Assurer la configuration uniforme des serveurs et le suivi de santé en temps réel.
  • Solution : Automatisation du provisionnement via playbooks Ansible, orchestration Docker Compose et supervision Grafana/Prometheus.
  • Résultat : Déploiement 100% reproductible avec métriques réseau et système centralisées.
  • Ubuntu
  • Nginx
  • Flask
  • PostgreSQL
  • Docker Compose
  • Ansible
  • Prometheus
  • Grafana

03 Réseau · Sécurité

Infrastructure Réseau & Sécurité FortiGate

Contexte : Isolation et sécurisation des flux au sein d'une infrastructure réseau multi-services.

  • Défi : Bloquer les accès non autorisés tout en maintenant la fluidité inter-VLAN.
  • Solution : Segmentation du réseau en 3 zones (VLANs), filtrage strict par pare-feu FortiGate et configuration des règles NAT.
  • Résultat : Isolation étanche des zones sensibles et validation par tests d'intrusion.
  • FortiGate
  • VLAN
  • NAT
04 Système · Automatisation

Administration Windows Distante via Ansible

Contexte : Gestion centralisée à distance d'un parc de machines sous Windows Server.

  • Défi : Supprimer la maintenance manuelle répétitive sur chaque poste.
  • Solution : Développement de scripts Ansible WinRM pour l'installation logicielle, l'exécution de commandes et la gestion de fichiers.
  • Résultat : Exécution simultanée des tâches d'administration sur tout le parc en quelques secondes.
  • Ansible
  • Windows Server
  • WinRM
